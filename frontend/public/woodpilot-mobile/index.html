      Comprendre les calculs

      Triangle rectangle uniquement. La diagonale est le plus grand côté. L’angle α se mesure entre la base et la diagonale.

      Diagonale² = base² + hauteur²
      tan α = hauteur / base
      sin α = hauteur / diagonale
      cos α = base / diagonale
